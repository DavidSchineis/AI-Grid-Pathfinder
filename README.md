## How to Run
Clone this repository
```bash
git clone https://github.com/DavidSchineis/AI-Grid_Pathfinder.git
```

Ensure Python 3.11+ is installed and install required libraries:
```bash
pip install -r assets/requirements.txt
```

Run the simulation:
```bash
python main.py
```
